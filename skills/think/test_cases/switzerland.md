# Evaluation Case: Switzerland Neutrality

## Purpose

This evaluation tests whether the reasoning skill can analyze a complex historical and geopolitical system.

The test evaluates whether the agent can:

- move beyond factual summaries
- identify causal mechanisms
- build a reusable model
- distinguish correlation from mechanism
- analyze tradeoffs
- identify boundaries and counterexamples
- compress understanding without losing important details

---

# User Input

## Prompt

How does Switzerland maintain neutrality over the years?

Explain through its policies, decisions, and examples.

---

# Expected Reasoning Objectives

The agent should infer that the user is not only asking:

"Why is Switzerland neutral?"

The deeper question is:

"How does a small country maintain strategic independence in a world dominated by larger powers?"

The response should aim for:

- understanding
- reusable mental model
- implications

---
