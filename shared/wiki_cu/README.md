## Philosophy

These guides focus on **what you need to do** rather than comprehensive documentation. For detailed reference, see [`docs/wiki/`](../wiki/README.md).

## Getting Started

1. Start with [01-setup.md](01-setup.md) to install and configure
2. Learn the daily commands in [02-daily-commands.md](02-daily-commands.md)
3. Try a workflow: [03-feature-workflow.md](03-feature-workflow.md) or [04-cicd-automation.md](04-cicd-automation.md)
4. Reference [appendix-concepts.md](appendix-concepts.md) when you need deeper understanding
